# 素材工具台

包含 Cocos 单文件 HTML 5MB 压缩、GLB 模型贴图压缩、特效透明贴图生成、序列帧转换、绿幕抠像和素材矢量分离工具。所有素材均在浏览器本地处理。

一个完全在浏览器本地运行的素材处理工具集合，包含：

- Cocos HTML 压缩：拖入包含 `window.__zip` 或 `window.__adapter_zip__` 的单文件 HTML，使用本地 WebP 与 MP3 WASM 压缩并导出 5MB HTML 和三种方向提交包。
- GLB 模型优化：默认输出 Cocos Creator 可直接导入的标准 GLB，并可同时缩小 GLB 内嵌 PNG、JPEG 或 WebP 贴图。无贴图模型也能处理。
- Meshopt 和 Draco 输出会写入对应的 glTF 压缩扩展，只适用于明确支持这些扩展的运行时；不要把这两种文件直接导入 Cocos Creator 编辑器。
- GLB 模型压缩与特效贴图生成现在是两个独立入口。特效工具上传参考图后自动分析主色、爆点和放射方向，重建光条、碎片、中心爆闪与柔光粒子四类透明 PNG；支持组合动画预览、重新随机、尺寸、变体、颜色、亮度和柔边调节，并可单张或连同参数 JSON 一起打包导出。
- 序列帧动画：处理 GIF、MP4 和 PNG 序列，支持拖入单个 PNG 序列文件夹，以 256、128、64 色或原像素无损档位导出原尺寸压缩序列 ZIP 和 Cocos 资源。
- 绿幕序列帧：拖入绿幕 MP4、MOV 或 GIF，自动从画面四角取样，也可点击预览精确取色；支持调节绿幕阈值、边缘柔化与去绿溢色，并导出透明 PNG 序列 ZIP。
- 素材矢量分离器：普通模式按连通区域分离图片素材；特效模式自动估算主色、爆点与放射方向，生成光条、碎片、爆闪和亮点四类纯 SVG，并可同时导出 PNG。

## 在线使用

仓库启用 GitHub Pages 后，打开 Pages 提供的网址即可使用，无需下载安装包。图片和素材默认只在浏览器本地处理，不会上传到服务器。

## 本地预览

需要 Node.js 18 或更高版本：

```powershell
node server.mjs
```

然后打开 `http://127.0.0.1:4176/`。
